# Julia Luersen Portfolio

Portfolio estático com HTML, CSS e JavaScript, preparado para desenvolvimento e build com Vite.

## Requisitos
- Node.js 20+ recomendado
- npm

## Instalação
```bash
npm install
```

## Desenvolvimento
```bash
npm run dev
```

## Build de produção
```bash
npm run build
```

O resultado fica em `dist/`.

## Estrutura
- `index.html` — página inicial
- `pages/` — projetos
- `css/style.css` — estilos e responsividade
- `js/` — modal e navegação
- `assets/` — coloque aqui as imagens originais do projeto

As imagens não foram incluídas nesta entrega porque não estavam entre os arquivos enviados.
